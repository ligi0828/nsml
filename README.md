# Minecraft启动器 - Python实现

基于Python 3和PyQt5的Minecraft启动器，支持BMCLAPI镜像源加速。

## 功能特性

- ✅ 支持原版Minecraft版本下载和启动
- ✅ 使用BMCLAPI镜像源加速下载
- ✅ 多线程下载管理器
- ✅ 图形用户界面（PyQt5）
- ✅ 版本管理（安装、删除、启动）
- ✅ 资源文件管理
- ✅ 库文件管理
- ✅ 自定义Java路径
- ✅ 内存设置
- ✅ 窗口设置
- ✅ 离线模式
- ✅ 下载进度显示
- ✅ 日志输出

## 安装依赖

```bash
pip install -r requirements.txt
```
